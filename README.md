# E-Commerce Sales and Customer Behavior Analysis Using Python

## Project Overview
This project focuses on analyzing e-commerce sales data and customer purchasing behavior using Python. The objective is to identify sales trends, customer preferences, product performance, and business insights through data analysis and visualization.

## Dataset Details
- Total Records: 138,116
- Original Columns: 46
- Data Period: 2021–2025
- Dataset Format: CSV
- Source: Kaggle

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Project Activities
1. Data Loading and Understanding
2. Data Cleaning and Preprocessing
3. Exploratory Data Analysis (EDA)
4. Monthly and Year-wise Sales Analysis
5. Sales Channel and Payment Analysis
6. Customer Segmentation Analysis
7. Regional Sales Analysis
8. Product and Brand Performance
9. Marketing Channel Analysis
10. Customer Rating and Review Sentiment Analysis
11. Discount and Profit Analysis
12. Data Visualization

## Key Findings
- Mobile App generated the highest sales revenue among sales channels.
- Electronics was the highest-revenue product category.
- South region recorded the highest regional revenue.
- Organic Search generated the highest marketing channel revenue.
- Discounts above 50% resulted in negative profit.
- Revenue and profit remained relatively stable between 2021 and 2025.

## Business Recommendations
The project provides recommendations to improve sales performance, customer retention, marketing strategies, delivery performance, and profitability.

## Conclusion
This project demonstrates how Python-based data analytics can transform raw e-commerce data into meaningful business insights and support data-driven decision-making.
